New build for Raspberry Pi. ChangeLog:

- New firmware
- Improved SD card performance
- Added USB mass storage devices support
- Added ext2 filesystem support (painfully slow with SD card, tolerable with USB memory stick)

Tarball: [raspberry-pi-uboot-20120707.tar.gz](http://people.freebsd.org/~gonzo/arm/rpi/raspberry-pi-uboot-20120707.tar.gz) 

SD card image (32Mb): [raspberry-pi-uboot-20120707.img](http://people.freebsd.org/~gonzo/arm/rpi/raspberry-pi-uboot-20120707.img)
